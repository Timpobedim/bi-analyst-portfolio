# 05 — Маржинальность и скидки

**Вопрос:** где сеть зарабатывает и сколько отдаёт скидкой?
**Адресат:** категорийный менеджер.

Выручка и прибыль ведут себя по-разному: категория может расти в обороте и терять деньги, если рост держится на акции.

## Что сейчас в данных

Маржинальность по категориям — от **32,8 %** у бытовой химии до **18,1 %** у мяса и рыбы:

| Категория | Маржа |
|---|---|
| бытовая химия | 32,8 % |
| напитки | 30,0 % |
| детское | 29,1 % |
| бакалея | 25,7 % |
| овощи и фрукты | 22,4 % |
| молочное | 20,6 % |
| мясо и рыба | 18,1 % |

Отдано скидкой за период — **18,9 млн ₽**. У **27 товаров** не заполнен поставщик, и на них приходится **2,9 %** выручки.

## На что смотреть внимательно

**«Отдано скидкой» — это не убыток.** Показатель считается как разница между ценой без скидки и тем, что пробито на кассе. Часть этих покупок без скидки просто не состоялась бы. Но это цена, которую стоит знать, прежде чем расширять акцию, — и в кассовых данных её нет напрямую, она выводится из доли скидки в позиции.

**Строка «не указан» в поставщиках — не поставщик, а дыра в справочнике.** Прятать её нельзя: тогда сумма по поставщикам перестанет сходиться с общей выручкой, и расхождение будет искать уже кто-то другой и в другом месте.

**Маржинальность здесь валовая:** выручка минус себестоимость товара. Аренда, зарплаты и реклама в неё не входят — они на дашборде финансов.

Витрина `продажи_позиции`. Собирается командой `bi dashboard margin`.
