# 02 — План и факт

**Вопрос:** выполняет ли сеть план и какие магазины отстают?
**Адресат:** директор по рознице.

Экран для разбора на планёрке.

## Что на странице

| Блок | Что показывает |
|---|---|
| Карточки | выполнение плана по сети, месяцев с выполненным планом, отклонение в рублях, магазинов выше плана |
| План и факт по месяцам | парные столбики: факт рядом с планом |
| Магазины | таблица: факт, план, выполнение, сколько месяцев из скольких закрыто |
| Худшие месяцы | восемь случаев с наибольшим отставанием |

## Что сейчас в данных

- Выполнение плана по сети — **92,6 %**.
- Выше плана за период — **2 магазина из 12**.
- Пар «месяц — магазин» с выполненным планом — **60 из 273**.
- Худший случай: «Москва-10», сентябрь 2025 года, **72,5 %**.

## На что смотреть внимательно

**Главное здесь — не подсветить отстающих, а отделить тех, кто не выполнил план по своей части, от тех, у кого месяц был закрыт.** Февраль 2026 года у одного магазина — месяц ремонта: план не снимали, а работать было негде. Если разбирать такой случай наравне с остальными, разбор превращается в поиск виноватых там, где виноват график работ.

**План ставится «от достигнутого» с амбицией, и амбиция по магазинам разная.** Это не условность генератора, а то, как планы ставят в жизни: по одним магазинам они систематически мягче, чем по другим. Если бы план был одинаково напряжённым для всех, его не выполнял бы вообще никто — и колонка «выполнение» перестала бы что-либо означать. Такую вырожденную панель легко не заметить: она выглядит как плохой месяц, а на самом деле это ошибка в том, как построен показатель.

## Источник

Витрина `продажи_месяц` (факт из продаж, план из таблицы `план`). Собирается командой `bi dashboard plan_fact`.
