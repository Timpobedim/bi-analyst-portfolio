# 11 — Остатки и оборачиваемость

**Вопрос:** сколько денег лежит в запасе и как быстро он обновляется?
**Адресат:** директор по логистике.

## Что на странице

| Блок | Что показывает |
|---|---|
| Карточки | запас на последний месяц, оборачиваемость, запас в днях, доля ассортимента под учётом |
| Запас по месяцам | линия остатка в рублях по себестоимости |
| Оборачиваемость по месяцам | линия: сколько раз за месяц обновился запас |
| Месяцы | таблица: остаток, штуки, себестоимость продаж, оборачиваемость, запас в днях |
| Средний запас по магазинам | горизонтальные полосы |

## Что сейчас в данных

- Запас на последний месяц — **5,4 млн ₽** по себестоимости.
- Оборачиваемость — **1,25 раза в месяц**, то есть запас примерно на **24 дня**.
- Под складским учётом **200 позиций из 900** — 22 % каталога.

## На что смотреть внимательно

**Главная ловушка этой страницы — считать оборачиваемость по всей себестоимости продаж.** Складской учёт в выгрузке ведётся не по всему ассортименту, а по выборке позиций. Если поделить продажи всех 900 товаров на остаток по 200, оборачиваемость завысится примерно втрое. Поэтому и числитель, и знаменатель здесь ограничены одними и теми же товарами, и об этом сказано прямо на странице.

**Остатки — снимок на первое число месяца, а не среднедневной запас.** Колебания внутри месяца этим данным недоступны, и оборачиваемость по ним получается грубее, чем могла бы быть по ежедневным остаткам.

**Запас на 24 дня — это норма, а не достижение.** Ориентир для продуктовой розницы — 20–30 дней; запас на девять месяцев, который получался в первой версии данных, означал бы, что скоропортящееся списали бы раньше, чем продали.

## Источник

Витрины `остатки_месяц` и `товар_месяц` по пересечению товаров под учётом. Собирается командой `bi dashboard stock`.
