# 04 — ABC-анализ ассортимента

**Вопрос:** какие товары дают выручку, а какие занимают полку?
**Адресат:** категорийный менеджер.

Группа A — первые 80 % выручки, B — до 95 %, C — остальное. Границы считаются накопленной долей через оконную функцию, а не проставляются руками.

## Что на странице

| Блок | Что показывает |
|---|---|
| Карточки | товаров в группе A, доля выручки группы A, позиции без продаж, выручка ассортимента |
| Группы ABC | таблица: товаров, доля позиций, выручка, доля выручки, прибыль |
| Категории | горизонтальные полосы по выручке |
| Топ-15 товаров | таблица с группой, выручкой, прибылью и штуками |
| Хвост ассортимента | десять позиций группы C с наименьшей выручкой |

## Что сейчас в данных

| Группа | Товаров | Выручка |
|---|---|---|
| A | 458 | 827,6 млн ₽ |
| B | 255 | 155,6 млн ₽ |
| C | 187 | 51,9 млн ₽ |

Каталог — 900 позиций; непроданных за два года нет ни одной.

## На что смотреть внимательно

**Правило «20 % позиций дают 80 % выручки» здесь не выполняется, и это нормально.** В группу A попали 458 товаров — больше половины каталога. Так и бывает в продуктовой рознице: ассортимент ровный, резких лидеров нет, потому что хлеб и молоко покупают все. Если бы дашборд подгонял границы под красивое «20/80», он показывал бы не ассортимент, а ожидание от него.

**Прежде чем выводить позицию из группы C, стоит посмотреть, не покупают ли её вместе с чем-то дорогим.** В этих данных такой связи не видно — совместных покупок никто не считал, — но в жизни она бывает решающей: товар с нулевой выручкой может держать чек, в котором лежит вся остальная корзина.

## Источник

Витрина `товар_месяц` и справочник товаров. Собирается командой `bi dashboard abc`.
